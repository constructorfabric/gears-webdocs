# Guides

Step-by-step tutorials that walk you through building real applications with Gears.

## Learning path

| Guide | You have | You'll learn |
|---|---|---|
| [Green Project](./green-project) | Nothing -- starting fresh | Create a workspace, scaffold a gear, build a full REST+DB application |
| [Brown Project](./brown-project) | An existing Gears app | Add gears, wire inter-gear communication, extend with background workers |
| [Migration Project](./migration-project) | A non-Rust application | Strategy and patterns for migrating to Gears from other languages |

## Prerequisites

All guides assume you have completed the [Getting Started](/intro/getting-started) steps:

- [Rust](https://rust-lang.org/tools/install/) installed
- [Protobuf](https://protobuf.dev/installation/) installed
- `cargo gears` CLI installed (`cargo install cargo-gears`)
